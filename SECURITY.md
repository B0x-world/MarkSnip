# Security policy

If you find a vulnerability in MarkSnip, **do not** open a public issue.

Report it privately through [GitHub private vulnerability reporting](https://github.com/B0x-world/MarkSnip/security/advisories/new) on this repository.

We will acknowledge the report and work on a fix before any public disclosure.
